# CampusSignal Ghana
# Technical Requirements Document

## 1. Project Purpose

CampusSignal Ghana is a multi-university platform
designed to make campus information and student
services easier to access.

The first university to be supported will be
Koforidua Technical University (KTU).

## 2. User Categories

The platform will support the following users:

1. Visitors
2. Students
3. University Staff
4. SRC and Class Representatives
5. University Administrators
6. Super Administrator

## 3. User Authentication

- Users will register using their email addresses.
- Users will log in using email and password.
- Student and staff accounts will require verification.
- Passwords must be securely protected.
- Users will have permissions based on their roles. 


## 4. Campus Navigation and Building Directory

The platform must help students locate buildings,
lecture halls and university offices.

### Required Features

1. Search for buildings by name.
2. Display building photographs.
3. Display building locations on an interactive map.
4. Provide written directions to each building.
5. Show nearby landmarks.
6. Display lecture room numbers and floor information.
7. Allow administrators to upload multiple building photos.
8. Allow administrators to update building information.
9. Allow students to report incorrect locations.

### Navigation Technology

The platform will use OpenStreetMap-based mapping.

### Offline Access

Students should be able to save selected campus
maps and directions for offline access.


## 5. Accommodation Finder

Students should be able to find available accommodation
around their university.

### Required Features

1. Display hostel names and locations.
2. Display hostel photographs.
3. Display accommodation prices.
4. Show available rooms.
5. Display hostel owners' contact details.
6. Allow students to view hostel locations on a map.

### Management

Only the platform owner and authorised university
administrators can add or update hostel listings.

Hostel bookings and payments will not be processed
inside the platform.

## 6. Printing Services Finder

Students should be able to locate printing and
photocopying shops around campus.

### Required Features

1. Display printing shop names.
2. Display shop photographs.
3. Show shop locations on a map.
4. Display available services.
5. Display contact numbers.
6. Display opening hours.

### Management

Only the platform owner and authorised university
administrators can add or update printing shop listings.


## 7. University Announcements

The platform must provide a central place for
official university announcements.

### Announcement Categories

1. Lecture venue changes
2. Examination timetables
3. SRC announcements
4. Scholarship opportunities
5. Events and programmes
6. General university announcements

### Required Features

- Students can view announcements.
- Students can comment on announcements.
- Students can receive notifications.
- Authorised users can publish announcements.
- Announcement publishers must have appropriate permissions.

## 8. Student Reporting System

Students should be able to report campus problems.

### Examples

1. Electricity outages
2. Water shortages
3. Damaged facilities
4. Incorrect lecture hall locations

### Required Features

- Students can submit reports.
- Reports should be visible immediately.
- Unverified reports must be clearly labelled.
- Authorised administrators can review reports.
- Administrators can update report status.

## 9. Study Partner Finder

Students should be able to find other students
who are interested in studying similar courses.

### Required Features

1. Search by course.
2. Search by department.
3. Search by academic level.
4. Create study groups.
5. Find students offering academic assistance.

## 10. Student Marketplace

Students should be able to advertise products
and services to other students.

### Products

- Textbooks
- Calculators
- Laptops
- Student essentials

### Services

- Graphic design
- Website development
- Tutoring
- Laptop repairs

### Required Features

1. Students can create advertisements.
2. Students can upload product photographs.
3. Students can provide descriptions and prices.
4. Interested students can contact sellers.
5. Users can report suspicious advertisements.

### Transactions

All transactions happen directly between
students and business owners.

CampusSignal will not process payments initially.

## 11. Administration System

CampusSignal will have two levels of administration.

### Super Administrator

The platform owner will be able to:

1. Add and remove universities.
2. Manage university administrators.
3. Monitor platform activities.
4. Manage user accounts.
5. Change platform name and logo.
6. Manage platform-wide settings.
7. Control future monetisation features.

### University Administrators

Each university administrator will be able to:

1. Manage their university information.
2. Add and update buildings.
3. Upload building photographs.
4. Add hostel and printing shop listings.
5. Manage announcements.
6. Review student reports.
7. Manage verified student and staff accounts.

University administrators must only manage
their assigned university.

## 12. Security Requirements

The platform must:

1. Protect user passwords.
2. Use secure authentication.
3. Apply role-based access control.
4. Protect university data from unauthorised access.
5. Validate information submitted by users.
6. Protect uploaded photographs and files.
7. Maintain administrative activity records.

## 13. Branding and Appearance

The platform should support:

1. Configurable application name.
2. Configurable logo.
3. White and light-grey main colours.
4. Dark mode.
5. English language.
6. Responsive website and mobile interfaces.

## 14. Future Expansion

CampusSignal will initially launch at Koforidua
Technical University.

The system must support adding more universities
without rebuilding the entire application.
