# CampusSignal Ghana

## Project Overview

CampusSignal Ghana is a university campus information
and services platform.

## First University

Koforidua Technical University (KTU).

## Main Objectives

1. Help students locate lecture halls and offices.
2. Provide campus maps and written directions.
3. Share verified university announcements.
4. Help students find accommodation.
5. Help students locate printing services.
6. Connect students with study partners.
7. Provide a student marketplace.

## Target Users

- Students
- University staff
- SRC and class representatives
- University administrators
- Platform administrators
- Visitors

## Technology

- Website: Next.js
- Mobile application: React Native
- Backend: Supabase
- Database: PostgreSQL
- Version control: Git and GitHub
